# CRUD de clientes

Tarea de la Semana 2 de Aplicaciones Web en UNIANDES. Permite registrar, listar, editar y eliminar clientes. Usa PHP con POO, MySQLi, MySQL o MariaDB, HTML5 y CSS3. La clase `Cliente` reúne las operaciones del CRUD.

## Cómo ejecutarlo en XAMPP

1. Coloca la carpeta `crud-clientes` dentro de `htdocs` e inicia Apache y MySQL.
2. En [phpMyAdmin](http://localhost/phpmyadmin/), importa `base_de_datos.sql`. Crea la base `crud_clientes` y la tabla `clientes`.
3. Copia `config/database.example.php` como `config/database.php`. Edita esa copia con el servidor, puerto, usuario y contraseña de tu instalación.
4. Abre [http://localhost/crud-clientes/](http://localhost/crud-clientes/).
